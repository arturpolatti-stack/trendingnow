# Materiais do experimento

Modelos para executar o protocolo de [EXPERIMENT.md](../EXPERIMENT.md). Todos os arquivos são **modelos vazios**: nenhum campo contém dado observado. Copie cada modelo para um arquivo novo por oportunidade ou sessão (ex.: `ficha-O1.md`, `sessao-P01.md`) e preencha somente com observações reais.

| Modelo | Uso | Requisitos |
| --- | --- | --- |
| [01-capacidade-e-baseline.md](01-capacidade-e-baseline.md) | O que a lojista consegue criar e como pesquisa hoje. | Questão aberta 1 do PRD |
| [02-registro-de-fontes.md](02-registro-de-fontes.md) | Estado de acesso e direitos por fonte. | DATA-01, DATA-02 |
| [03-ficha-de-oportunidade.md](03-ficha-de-oportunidade.md) | Evidências separadas por dimensão, com proveniência. | R-01 a R-04, R-09, DATA-03 a DATA-06 |
| [04-briefing.md](04-briefing.md) | Briefing executável no Canva. | R-05, campos mínimos do experimento |
| [05-diario-da-sessao.md](05-diario-da-sessao.md) | Registro da sessão observada e das medidas. | Medidas do piloto |

Ordem de preparação: 01 → 02 → 03 (duas oportunidades) → sessão com 05 → 04.

Regras: ausência nunca vira zero; atenção social não é demanda na Etsy; anúncios ativos não são vendas; sem credenciais, contatos ou dados de compradores.
